# LeadsMap

LeadsMap is a free Chrome extension for turning Google Maps search results into a local business lead list.

Official website: [https://www.leadsmap.io/](https://www.leadsmap.io/)

Install guide: [https://www.leadsmap.io/how-to-install](https://www.leadsmap.io/how-to-install)

## Local lead list workflow

1. Search Google Maps for one focused niche and city.
2. Review the visible business results before exporting.
3. Use LeadsMap to collect business names, categories, addresses, phone numbers, websites, ratings, and map links.
4. Clean duplicates and segment the spreadsheet before outreach.

This repository is a lightweight public note for LeadsMap product information, support links, and Google Maps lead research workflows.
