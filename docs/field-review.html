CRM import prep notes

Review fields before outreach

  • Keep business name, website, phone, address, category, rating, review count, and map URL in separate columns.
  • Preserve the city, niche, and search phrase that produced the exported records.
  • Flag records with missing phone numbers, missing websites, or duplicate domains for manual review.
  • Use the original Google Maps URL as a source link when a teammate needs to verify a listing.

This page is a public field-review note for LeadsMap users preparing local business data for CRM import or outreach workflows.
